# webservco/app-skeleton

An opinionated application project skeleton / project starter.

## Includes

- SvelteKit
- shadcn-svelte
- Dark mode
- unplugin-icons
- Lucia Auth v3
- Superforms
- mysql2
- Logger (Winston)
- PWA
- multiple environments

## Developing

```bash
npm run dev -- --open

npm run lint && npm run check
```

---

## Setup

- Customize `README.md`;
- Customize `package.json`;
- Customize `static/app.webmanifest`;
- Customize `static/img/icons`;
